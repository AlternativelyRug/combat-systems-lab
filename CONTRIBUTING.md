# Working on the sample

Keep this repository independent of private commercial projects. Do not import game code, authored assets, balance data, internal documents, account identifiers or credentials.

One file has one clear role. Edit in place; use Git history rather than version-numbered copies. New behavior begins with a failing test, an explicit rule and a small change. Run `python tools/check.py` before committing. Add intended public files to `tools/public-files.txt` after reviewing their contents.

Keep actual human contribution and tool assistance accurate. Do not claim tests or environments that were not run. Discuss changes to combat rules separately from refactoring.
